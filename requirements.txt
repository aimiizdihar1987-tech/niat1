# Niat — Python dependencies.
#
# The web server (server.py) and everything it imports at startup use ONLY the
# Python standard library: http.server, urllib, sqlite3, smtplib, hmac, zipfile.
# There is no web framework and no LLM SDK to install.
#
# The packages below are needed by niat_google.py (Path B — direct Google
# Forms/Classroom calls used by Agent 5 and Agent 6). It is imported LAZILY, so
# the server still boots without them, but the Cloud Run image installs them
# because /api/distribute-direct and the reminder job depend on them.

# google.auth.transport.requests needs `requests`; the [requests] extra makes
# that explicit instead of relying on google-auth-oauthlib to pull it in.
google-auth[requests]>=2,<3
google-auth-oauthlib>=1,<2
google-api-python-client>=2,<3
