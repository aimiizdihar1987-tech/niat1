    Manual distribution (Apps Script)

    Fallback method — only needed if the one-click "Send to Classroom" on the Worksheet page is not set up. Uses the Class and due date you set there.

    Script & steps
    1. Open script.google.com → New project.
    2. Delete the sample code, then paste the script below (use Copy script).
    3. Enable Classroom: Services ➕ → Google Classroom API → Add.
    4. Save, then Run ▶ niatDistribute and Allow.

    Save to Drive + Upload to Classroom

    Saves this lesson plan as a Google Doc in your Drive and posts it to your designated RPH Classroom. Runs under your own moe-dl account.

    Manual method (Apps Script) — fallback
    1. Open script.google.com → New project, delete the sample code, paste the script below.
    2. One-time: click Services (the ＋ on the left) → Google Classroom API → Add.
    3. Step 1: click Run ▶ niatToClassroom, Allow permissions, then open the Execution log to see your Classrooms + IDs.
    4. Step 2: paste your designated Classroom's ID into COURSE_ID at the top, then Run again.
    5. Done — the plan is in your Drive and posted to Classroom.
